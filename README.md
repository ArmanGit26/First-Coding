# Aperture Folio — Photography Portfolio Website

Pure HTML + CSS + JavaScript. No build step, no backend needed.

## How to run
1. Just double-click `index.html` (or right-click → Open with → your browser).
   That's it — it's a static site.
2. Optional: to avoid any browser file:// quirks, serve it locally instead:
   - If you have Python installed: `python3 -m http.server 8000` in this folder,
     then open http://localhost:8000
   - If you have VS Code: install the "Live Server" extension, right-click
     index.html → "Open with Live Server"

## Files
- `index.html` — page structure (sidebar nav, hero section, gallery)
- `style.css`  — all styling (CSS variables, Flexbox sidebar, Grid gallery)
- `script.js`  — gallery data + the filter buttons (All/Portrait/Landscape/Street)
